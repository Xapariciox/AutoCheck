# AutoCheck
App móvil de mantenimiento preventivo de vehículos: estima el kilometraje, proyecta cuándo cambiar cada consumible (gasolina, diésel, híbrido y eléctrico) y lo resume en un semáforo. Incluye un pasaporte digital inmutable con firma HMAC y QR. React Native + Spring Boot 3 + PostgreSQL + Docker.
